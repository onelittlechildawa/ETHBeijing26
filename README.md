[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fonelittlechildawa%2FETHBeijing26)

## Introduction

ChainLens is a Web3 project risk analysis tool for people outside the crypto circle. Give it a project name, website, whitepaper, GitHub link, or contract address, and it gathers public evidence into a structured report so users can compare project claims with on-chain and off-chain signals.

## Tech Stack

- Frontend: Vite, Vanilla JavaScript, Lucide Icons
- Backend: Node.js, Express
- Web3: Viem, GoPlus, DEXScreener, CoinGecko, Sourcify
- AI: OpenAI-compatible API
- Deploy: Vercel, Vercel Blob

## 项目简介

ChainLens 是一个面向普通用户的 Web3 项目风险分析工具。用户可以输入项目名称、官网、白皮书、GitHub 链接或合约地址，系统会收集公开数据并生成一份结构化报告，帮助用户判断项目宣传和链上/链下证据是否一致。
